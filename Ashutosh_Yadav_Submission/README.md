## Project summary

A B2B India administrative-directory API covering:

**Country → State → District → Sub-District → Village**

The existing implementation includes authentication, API keys, search/autocomplete, admin controls, rate limiting, security headers, request logging, Prisma/PostgreSQL persistence and MDDS-style data import support.
