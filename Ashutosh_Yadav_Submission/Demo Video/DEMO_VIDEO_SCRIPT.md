# Demo Video Script

**Presenter:** Ashutosh Yadav  
**Target length:** 5–7 minutes

### 0:00–0:30 — Introduction
Introduce the India Administrative Directory API and its B2B use case.

### 0:30–1:15 — Architecture
Show the repository and explain Node.js/Express + TypeScript + Prisma + PostgreSQL/NeonDB.

### 1:15–2:30 — API demonstration
Show health, authentication, state listing, hierarchy navigation, search and village autocomplete.

### 2:30–3:30 — Security
Show JWT login, API key handling, write-operation secret validation, rate-limit headers and masked request logging.

### 3:30–4:30 — Admin
Show user listing, plan/status controls, state access management and API logs.

### 4:30–5:30 — Database and dataset
Show the Prisma schema, seed data and MDDS-style importer.

### 5:30–6:00 — Closing
Summarize the project features and the production-extension path.

The final screen recording should clearly show the GitHub repository and the working API responses.
